So sánh kĩ thuật if-else và switch-case 
Kiểm tra biểu thức phức tạp :
- với if-else thì rất mạnh có thể so sánh khoảng
- với switch-case còn hạn chế vì chỉ so sánh nghiêm ngặt ===

Tra cứu rời rạc :
- với if-else thì khá dài dòng , lặp tên biến nhiều lần
- với switch-case thì gọn gàng , trực quan , phân nhánh rõ ràng

Rủi ro cú pháp :
- với if-else thì ít lỗi cú pháp
- với switch-case thì dễ quên break gây trôi lệnh

Đề xuất sử dụng :
Nên dùng switch-case khi cần phân loại các giá trị cố định
Nên dùng if-else khi cần kiểm tra điều kiện hoặc khoảng giá trị
